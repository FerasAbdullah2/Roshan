# 🗓️ تقويم دوري روشن السعودي 2026 / 2027 · Roshn Saudi League Calendar

موقع بسيط (بدون خادم) يعرض جدول دوري روشن، ويتيح لك **اختيار الفرق التي تتابعها** ثم
**إضافة مبارياتها إلى تقويمك الشخصي** بموعدها ووقتها — بواجهة **عربية/إنجليزية**.

A serverless static site: pick the teams you follow and add their matches to your
personal calendar, with a bilingual **Arabic / English** interface.

## المميزات · Features
- 🌐 **عربي/إنجليزي** — زر تبديل اللغة يقلب النصوص والاتجاه (RTL/LTR) وأسماء الفرق.
- ⏱️ **عدّاد تنازلي** لأقرب مباراة (يتفاعل مع فرقك المختارة).
- 🛡️ **شعارات (كرِست)** على شكل دروع بألوان كل نادٍ ونجمته واختصاره.
- ⚙️ **اختيار فرقك** (يُحفظ تلقائياً) + تصفية «مباريات فرقي فقط».
- 📅 **إضافة لكل مباراة**: Google تقويم أو ملف `.ics` (آبل/أوت لوك).
- 🔔 **اشتراك يتحدّث تلقائياً**: روابط `webcal` — إذا تغيّر موعد مباراة، **يتحدّث تقويمك تلقائياً**.
  - للموسم كامل: `roshn-2026-2027.ics`
  - لكل فريق: `feeds/<teamId>.ics` (اشترك بفريقك فقط)

## 🔔 التحديث التلقائي للمواعيد · Auto-updating times
لو تغيّرت أوقات المباريات لاحقاً، المشتركون عبر **«اشترك» (webcal)** يحصلون على التحديث تلقائياً.
الطريقة:
1. عدّل المواعيد في `data.js` (أو أضِف إلى `MANUAL_FIXTURES`).
2. **زِد `SEASON.revision` بواحد** (يرفع `SEQUENCE` في كل حدث فيتعرّف تطبيق التقويم على التغيير).
3. شغّل `node build-ics.mjs` لإعادة توليد ملفات الاشتراك، ثم ادفع التغييرات.

تطبيقات التقويم تُحدّث اشتراكات `webcal` دورياً، فتظهر المواعيد الجديدة تلقائياً.
> ملاحظة: زر **«نزّل»** يعطي نسخة **ثابتة لمرة واحدة** (لا تتحدّث) — للتحديث التلقائي استخدم **«اشترك»**.

## توليد ملفات الاشتراك · Build feeds
```bash
node build-ics.mjs   # يكتب roshn-2026-2027.ics + feeds/<team>.ics لكل فريق
```

## 🛡️ الشعارات · Logos
الشعارات الافتراضية **كرِست مرسوم أصلي** بألوان كل نادٍ (تفادياً لحقوق الشعارات الرسمية).
لاستخدام شعار رسمي لنادٍ: ضع ملف الصورة في `logos/` واضبط `logoUrl` لذلك النادي في `data.js`،
مثال: `logoUrl: "logos/hilal.png"` — وإلا يبقى الكرِست المرسوم.

## التشغيل · Run
لا يحتاج تثبيت. افتح `index.html` مباشرة، أو انشره على أي استضافة ثابتة.
```
.                     # جذر المستودع
├─ index.html          # الصفحة
├─ styles.css          # التصميم
├─ data.js             # ★ البيانات (فرق + موسم + مواجهات + revision)
├─ schedule.js         # مولّد الجدول (34 جولة ذهاب وإياب)
├─ app.js              # الواجهة (عربي/إنجليزي) + العدّاد + التقويم
├─ build-ics.mjs       # يولّد ملفات الاشتراك
├─ roshn-2026-2027.ics # اشتراك الموسم الكامل (مولّد)
└─ feeds/<team>.ics    # اشتراك كل فريق (مولّد)
```

### النشر على GitHub Pages
**Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `/ (root)`.
سيصبح الموقع على `https://<user>.github.io/Roshan/`.

## ⚠️ ملاحظة عن البيانات · Data note
**الجولة الأولى مؤكدة رسمياً** (وسم «موعد مؤكد»). باقي الجولات **مولّدة تلقائياً** كدوري
ذهاب وإياب مكتمل (كل فريقين يلتقيان مرتين) والمواعيد **مبدئية** (وسم «موعد مبدئي») حتى صدور
الجدول الرسمي الكامل. عدّلها من `data.js`:
- `TEAMS` (الاسم عربي/إنجليزي، المدينة، الملعب، الألوان، `logoUrl`)
- `CONFIRMED_ROUND1` — مواجهات الجولة الأولى
- `MANUAL_FIXTURES` — تثبيت مباريات رسمية: `{ round, home, away, date, time, confirmed:true }`

> تقويم غير رسمي لأغراض المتابعة الشخصية · Unofficial personal-tracking calendar.
