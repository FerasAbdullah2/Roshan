# 🗓️ تقويم دوري روشن السعودي 2026 / 2027

موقع بسيط (بدون خادم) يعرض جدول دوري روشن، ويتيح لك **اختيار الفرق التي تتابعها** ثم
**إضافة مبارياتها إلى تقويمك الشخصي** بموعدها ووقتها (Google Calendar و Apple/Outlook عبر ملف `.ics`).

## المميزات
- **عدّاد تنازلي** لأقرب مباراة (يتفاعل مع فرقك المختارة).
- **اختيار فرقك**: اضغط على الفرق التي تتابعها (يُحفظ اختيارك على جهازك تلقائياً).
- **شعارات (كرِست)** مرسومة بألوان كل نادٍ (نتجنّب الشعارات الرسمية لحقوقها).
- **تصفية**: زر «مباريات فرقي فقط» يعرض مباريات فرقك المختارة فقط.
- **إضافة لكل مباراة**: زر **Google تقويم** (يفتح التقويم مباشرة) أو زر **ملف .ics**.
- **إضافة دفعة واحدة**: زر «نزّل مباريات فرقي» يعطيك ملف `.ics` واحد فيه **كل** مباريات فرقك — استورده مرة واحدة في أي تطبيق تقويم.
- **اشتراك تلقائي** عبر `webcal` برابط `roshn-2026-2027.ics` يتحدّث تلقائياً في تطبيق تقويمك (بعد النشر).
- الأوقات بتوقيت السعودية (UTC+3)، وواجهة عربية RTL.

## توليد ملف الاشتراك
ملف الموسم الكامل `roshn-2026-2027.ics` يُولَّد من البيانات:
```bash
node build-ics.mjs   # يكتب roshn-2026-2027.ics (306 مباراة)
```
شغّله بعد أي تعديل على `data.js` ليتحدّث ملف الاشتراك.

## التشغيل
لا يحتاج أي تثبيت. افتح `index.html` في المتصفح مباشرة، أو انشره على أي استضافة ثابتة
(GitHub Pages / Netlify / Vercel) — كلها ملفات ثابتة.

```
.                     # جذر المستودع
├─ index.html          # الصفحة
├─ styles.css          # التصميم
├─ data.js             # ★ البيانات (الفرق + الموسم + المواجهات المؤكدة)
├─ schedule.js         # مولّد الجدول (34 جولة ذهاب وإياب)
├─ app.js              # الواجهة + العدّاد + توليد ملفات التقويم
├─ build-ics.mjs       # يولّد ملف الاشتراك الكامل
└─ roshn-2026-2027.ics # ملف الاشتراك التلقائي (مولّد)
```

### النشر على GitHub Pages
1. **Settings → Pages** → اختر الفرع `main` والمجلد `/ (root)`.
2. سيصبح الموقع متاحاً على رابط `github.io`.

## ⚠️ ملاحظة عن البيانات
حتى تاريخ الإعداد، أعلنت رابطة الدوري **مواعيد أول 6 جولات ومواجهات الجولة الأولى فقط**.
لذلك:
- **الجولة الأولى**: مواجهاتها **مؤكدة** (وسم «موعد مؤكد»).
- **باقي الجولات**: مولّدة تلقائياً كدوري ذهاب وإياب مكتمل (كل فريقين يلتقيان مرتين)،
  والمواعيد **مبدئية/تجريبية** (وسم «موعد مبدئي»).

### كيف تُدخل الجدول الرسمي؟
كل شيء في ملف **`data.js`**:
- **الفرق**: عدّل مصفوفة `TEAMS` (الاسم، المدينة، الملعب، اللون).
- **الجولة الأولى**: عدّل `CONFIRMED_ROUND1`.
- **تثبيت مباريات رسمية**: أضف عناصر إلى `MANUAL_FIXTURES`، مثال:
  ```js
  { round: 3, home: "hilal", away: "nassr", date: "2026-08-27", time: "21:00", confirmed: true }
  ```
  أي مباراة هنا تحل محل المولّدة تلقائياً لنفس الفريقين، وتظهر بوسم «موعد مؤكد».

> تقويم غير رسمي لأغراض المتابعة الشخصية.
